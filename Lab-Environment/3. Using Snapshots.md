- **Snapshots** are saved states of a virtual machine at a specific point in time.
- A snapshot preserves the VM’s current configuration, installed software, and system state.
- Snapshots are useful because they let you return to a previously working state if the VM becomes corrupted or misconfigured.


For this test, we will:

```text
Calculate baseline hash
        |
        v
Take snapshot
        |
        v
Modify the system
        |
        v
Calculate new hash
        |
        v
Restore snapshot
        |
        v
Calculate hash again
```

The expected result is:

```text
H1 != H0
H2 == H0
```

---

# **Step 1 - Calculate the Baseline Hash**

Calculate a single SHA-256 value representing the files under `/etc`.

```bash
find /etc -type f -exec sha256sum {} \; 2>/dev/null | sha256sum
```

Baseline hash:

```text
2236aed00dad85ff8aa7b8ab8939ebe2b8bbc4a4d781f663ecf37811c9a2760b
```

We will refer to this value as:

```text
H0
```

---

# **Step 2 - Take a Snapshot**

With the Kali VM running, open the snapshot interface in VirtualBox.

![](/assets/3/img-1.png)

Navigate to:

```text
Snapshots
    |
    v
Current State
    |
    v
Take
```

![](/assets/3/img-2.png)

Create the snapshot.

This snapshot represents the system state associated with:

```text
H0
```

---

# **Step 3 - Modify the System**

Start or continue using Kali normally.

Make a small change to the system:

```bash
echo "test" >> /etc/hostname
```

This modifies `/etc/hostname`.

Because a file under `/etc` has changed, the resulting folder hash should also change.

---

# **Step 4 - Calculate the Hash Again**

Run the same command:

```bash
find /etc -type f -exec sha256sum {} \; 2>/dev/null | sha256sum
```

![](/assets/3/img-3.png)

We will refer to this second value as:

```text
H1
```

Expected result:

```text
H1 != H0
```

The different hash indicates that the contents included in the calculation are no longer identical to the baseline state.

---

# **Step 5 - Restore the Snapshot**

Return to the VirtualBox snapshot interface.

Select the snapshot created before modifying the system.

![](/assets/3/img-4.png)

When restoring the snapshot, uncheck:

```text
Create a snapshot of the current machine state
```

Then click:

```text
Restore
```

![](/assets/3/img-5.png)

VirtualBox should restore the VM to the previous saved state.

---

# **Step 6 - Calculate the Hash After Restore**

Start the VM again.

Run the same hash command:

```bash
find /etc -type f -exec sha256sum {} \; 2>/dev/null | sha256sum
```

![](/assets/3/img-6.png)

Result:

```text
2236aed00dad85ff8aa7b8ab8939ebe2b8bbc4a4d781f663ecf37811c9a2760b
```

We will refer to this value as:

```text
H2
```

Expected result:

```text
H2 == H0
```

The restored hash matches the original baseline hash.
