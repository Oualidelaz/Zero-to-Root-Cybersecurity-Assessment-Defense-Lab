```markdown
- Kali Linux is a Linux distribution designed for cybersecurity and penetration testing.
- It comes preloaded with many security tools, which saves time compared with installing each tool manually.
- The prebuilt VM can be imported directly into VirtualBox, avoiding the full installation process.
- Choose the 64-bit VirtualBox version from the official Kali Linux download page.

![](/assets/2/img-1.png)

- The downloaded archive must be extracted before the VM can be used.

![](/assets/2/img-2.png)

- After extraction, open the VirtualBox machine file to add Kali to VirtualBox.

![](/assets/2/img-3.png)
![](/assets/2/img-4.png)

- The default credentials shown in the lesson are:
  - Username: `kali`
  - Password: `kali`
- Kali may initially be configured with around 2 GB of RAM.
- Linux generally requires fewer resources than Windows for basic lab usage.
```
