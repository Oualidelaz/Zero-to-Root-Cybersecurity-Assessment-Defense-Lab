- Use Microsoft’s official Media Creation Tool to get the installation files.
- Create a Windows 10 ISO from the tool.
- Some personalization features may be limited without activation, but that does not affect the lab.


1. Download the **Windows 10 Media Creation Tool** from Microsoft. `windows 10 iso download`

![](/assets/1/img-1.png)


![](/assets/1/img-2.png)

- Choose **Create installation media for another PC**

![](/assets/1/img-3.png)

- Select **Windows 10, 64-bit**.

![](/assets/1/img-4.png)

- Choose **ISO file**, not USB.

![](/assets/1/img-5.png)

- Save the ISO somewhere easy to find.
- Wait for the Windows 10 ISO to download and be created.

- Open **VirtualBox** and create a **new** Windows 10 VM.

![](/assets/1/img-6.png)

- Keep the VM files and ISO together if that helps with organization.

![](/assets/1/img-7.png)

- Allocate RAM:
    - Around **4 GB minimum** for a typical system.
    - More RAM can be assigned if the host machine has enough available.
- Allocate CPU cores depending on the host system.
- Create a virtual disk of about **50 GB**.
- The virtual disk grows as data is added, so it will not necessarily consume the full 50 GB immediately.
- Start the VM.
- If VirtualBox reports that no bootable media is available, attach the downloaded **Windows 10 ISO**.

![](/assets/1/img-8.png)

- Mount the ISO and restart the VM.

![](/assets/1/img-9.png)

![](/assets/1/img-10.png)

- Begin the Windows installation.
- Select **I don't have a product key** if no key is available.

![](/assets/1/img-11.png)


- Choose **Windows 10 Pro** because it provides features useful for the labs, such as:
    - User and permission management
    - Remote Desktop
    - Additional administrative features

![](/assets/1/img-12.png)

- Choose **Custom: Install Windows only**.
- Select the virtual 50 GB disk and continue the installation.
- Wait while Windows installs and restarts.
- Complete the initial setup:
    - Region
    - Keyboard layout
    - User account
    - Basic Windows preferences
- Overall workflow:  
    **Media Creation Tool → Windows 10 ISO → VirtualBox VM → Attach ISO → Install Windows 10 Pro**
- After the Windows VM is ready, proceed to setting up the **Kali Linux VM** for the next lab.
